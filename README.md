

📖 Dyscover: Your AI Ally for Dyslexia
Dyscover is a specialized mobile intervention tool designed to empower students and individuals with dyslexia. Built with React Native and Firebase, this MVP transforms how people with learning differences interact with written language by reducing cognitive load and visual stress.

🌟 Dyslexia-Centric Features
✍️ Handwriting Flaw Detection
Writing can be as challenging as reading. Dyscover uses specialized image processing to:

Identify Letter Reversals: Automatically flags common mix-ups like 'b' vs 'd' or 'p' vs 'q'.

Analyze Spacing: Detects inconsistent word spacing and alignment issues that affect legibility.

Supportive Feedback: Provides gentle, constructive cues to help users refine motor skills without frustration.

📝 Intelligent Worksheet Analysis
Traditional worksheets are often too "busy" or overwhelming. This feature:

Segment Text: Breaks down dense blocks into manageable, bite-sized pieces.

Highlight Instructions: Uses visual cues to isolate key tasks, so the user knows exactly what to do first.

Reduce Visual Crowding: Adjusts the digital view to minimize the "jumbled" effect common for dyslexic readers.

⚡ Quick Scan & Listen
Instantly turn physical books into digital audio to bridge the gap between decoding and comprehension.

OCR Integration: High-speed Optical Character Recognition captures text from any surface.

Text-to-Speech (TTS): Uses natural voices to read text aloud, allowing the user to focus on the story or lesson rather than the struggle of reading.

🛠️ Tech Stack
Frontend: React Native (JavaScript/TypeScript)

Backend: Firebase (Cloud Storage & Functions)

Database: Firebase Firestore (Real-time data syncing)

Authentication: Firebase Auth (Secure, frictionless user login)

Intelligence: Custom AI models for handwriting and worksheet analysis.

📥 Getting Started
Prerequisites
Android Device (Version 7.0 or higher)

Camera permissions enabled (Required for Scanning and Handwriting detection)

Installation
Download the APK: Locate application-9feafd38-a551-4068-8113-ded72e285fea.apk in this repository.

Enable Permissions: Allow "Installation from Unknown Sources" in your Android settings.

Launch: Open Dyscover and start your journey toward more accessible learning.

🛡️ Secure & Reliable
Built on Firebase Authentication, we ensure that all user data—including scanned worksheets and personal progress reports—is encrypted and accessible only to the account owner.
